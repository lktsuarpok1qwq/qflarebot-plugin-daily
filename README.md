# 每日助手

QFlareBot 的模块化每日助手，支持通知、日历、天气、一言和运势，各模块独立配置

通知统一管理任务、对象、模板与发送记录，向 QQ 群聊或私聊定时发送 Markdown 公告，支持本地情景预览和发送测试

日历提供当年和明年的放假、调休及节日信息，支持人工编辑和每年重复的自定义节日，可通过变量组合公告，也可使用 `/假期`、`/假期 下个`、`/假期 剩余` 查询

支持主动查询城市当前天气与明天预报，使用和风天气接口

支持 `/一言` 随机获取一句话，或通过 `{{一言.今日}}` 将当天固定的一言加入公告

支持 `/运势` 查看帮助，或通过 `/运势 抽` 查询当天固定的个人运势
