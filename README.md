# 每日助手

QFlareBot 的模块化每日助手，支持 QQ 群聊和私聊，各模块独立配置

- **通知**：定时公告、任务与对象管理、共享模板、发送记录和发送测试
- **日历**：当年及明年的放假与调休、人工编辑、自定义节日和每年重复提醒
- **天气**：城市当天实况与预报、天气图片卡片与文字回复
- **一言**：随机语句，命令和公告文案独立配置
- **运势**：每日个人抽签与解签、图片卡片、文字回复和节日彩蛋
- **签到**：独立记录每日签到，可选接入通用积分钱包，连续签到奖励、群聊个人签到榜与自定义文案
- **絮语**：手动文案库、批量录入与排序、每日一篇、新文案优先与顺序循环、公告变量与已选内容浏览
- **文案**：自定义命令回复、公告变量、Markdown 情景预览和命令链接生成
- **卡面**：运势与天气共用内置背景与自定义图片、拖拽排版、文字与 Emoji、动态变量、本地样例和 Images 预览
